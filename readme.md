Даний проєкт реалізовує базу даних для магазину з таблицями orders, order_log, products, customers, order_items.

#### Логіка:

## FUNCTION calculate_order_total(p_order_id INT)
Функція обраховує загальну суму замовлення по його айді. COALESCE використаний для того, щоб виводити нуль у випадку, коли замлення пусте і не має айтемів всередині.

## PROCEDURE create_order(o_customer_id INT)
Створює в таблиці замовлень нове замовлення на айді введеного кастомера, дефолтно вказує загальну суму як 0, а дату створення як поточну дату.

## PROCEDURE add_product_to_order(p_order_id int, p_product_id int, p_quantity int)
Дана процедура додає продукт до замовлення, реалізовано спочатку через перевірку бажаної кількості продукту, у разі від'ємної чи 0 піднімається помилка. Далі в таблиці продуктів по айді продукту знаходяться бажані та їх дані передаються в тимчасові змінні. У випадку якщо на складі менше бажаної кілкьості, то піднміється помилка. Змінюється значення на складі кількості даного продукту. У кінці в order_items вставляються значення нового продукту замовлення.

## FUNCTION log_new_order()
Допоміжна функція тригеру, яка вставляє в таблицю order_log значення з нових рядків в таблиці замовлень.

Сам тригер створений нижче зз умовою виклику після INSERT в таблиці замовлень, та правила виклику допоміжної функції.

## FUNCTION update_order_total() та FUNCTION delete_order_total()
Допоміжні функції тригерів update_order_trigger та delete_order_trigger, які перераховують загальну суму замовлення в таблиці, після змін.
